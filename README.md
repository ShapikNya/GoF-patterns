# GOFPatternsDemo

Консольный проект на C#, демонстрирующий основные паттерны проектирования (Gang of Four).  
Каждый паттерн реализован в отдельном примере для наглядного изучения.

## 📌 Реализованные паттерны

- **Adapter** — преобразование интерфейса одного класса в интерфейс, ожидаемый клиентом.  
- **Builder** — пошаговое создание сложного объекта.  
- **Command** — инкапсуляция запроса как объекта, поддержка отмены и очередей команд.  
- **Decorator** — динамическое расширение функционала объекта.  
- **Facade** — упрощённый интерфейс к сложной системе.  
- **Factory Method** — создание объектов через фабричный метод, делегируя конкретный класс подклассам.  
- **Observer** — подписка на события объекта и уведомление подписчиков.  
- **Proxy** — заместитель объекта, контролирующий доступ.  
- **Singleton** — гарантированно один экземпляр класса.  
- **Strategy** — выбор алгоритма на лету.  
- **Template Method** — определение скелета алгоритма с возможностью переопределения шагов.
